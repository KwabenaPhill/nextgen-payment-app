# NextGen Payment App

The Next Gen Crew trip payment app: members, payments with history, trips, trip costs and WhatsApp reports.

Install: open https://kwabenaphill.github.io/nextgen-payment-app/ in Chrome on the phone, then menu > Add to home screen > Install.

- All data stays on each phone (key `nextgen_pay_v5`). Nothing personal is stored in this repository.
- Backups: Backup tab > Export Backup. Old Payment File (v4) backups restore too.

## Versions
- v5.1: NextGen Payment App name, Next Gen Crew logo and app icon, installable (manifest, service worker, icons). Same look as v5.0.
- v5.2: Smaller header logo, "Payment App" kept on one line.
- v5.0: payment history, auto-save, trips, trip costs, per-member WhatsApp reminders, date pickers and deadline countdown, overpayment shown, offline font.
